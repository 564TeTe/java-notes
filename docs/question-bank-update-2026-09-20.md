## 后续更新：全量短句版（第 46 版）

- 替换为最新附件的 662 道短句答案，全部题号与顺序按附件保留，已不含对比表格。
- 原先自动归档的 244 道重新进入主背，当前没有默认归档题。个人永久删除、笔记、收藏和复习记录保留。
- 撤销旧版自动归档只执行一次，状态随备份和云同步保存，之后手动删题不会在刷新时自动恢复。旧设备的 244 道归档未区分逐题手动删除与自动归档；这一批按新版恢复主背，永久删除例外。
- 仅提供题库 JS 时，导入器从现有题库保留真正被移出的题到回收站；再次导入同一文件不会重复题目或重复迁移。

```powershell
node scripts/import-optimized-question-bank.cjs '新版/question-bank.js'
```

## 上一版记录（第 45 版）

- 主背题库 418 道：保留原题号的旧题 347 道，新增题 71 道。
- 原题 244 道移入回收站，保留附件中的原文与归档原因；原先默认回收的 18 道均在其中。
- 新题库的题目顺序、答案、题型和学习分组原样保留。对比表格和列表可直接阅读；手机上的宽表格可左右滑动。
- 个人笔记、收藏、掌握程度依旧按原 ID 关联。手动恢复的题仍保留，永久删除的题不复活。已有手动删题或自建题时，个人页面数量可能与默认数量不同。
- 保留历史公司面经的来源关联；官方文档只作为参考资料，不计入公司面经。

`data/question-bank.js` 的 `questions` 是主背题，`archivedQuestions` 是可恢复的原题。`data/question-curation.js` 提供默认回收原因，实际恢复或删除状态保存在用户自己的数据中。版本更新到 45，用于更新离线缓存。

再次导入同样格式的附件：

```powershell
node scripts/import-optimized-question-bank.cjs '新版/question-bank.js' '新版/archive-original-questions.json'
```

导入器会拒绝题号重复、旧题无归档或来源缺失的数据；重新导入同一版不会重复题目。
