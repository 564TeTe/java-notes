# 手机阅读与更新稳定性

用户反馈手机端臃肿且出现“闪退”。按系统排错流程先量测：390px 手机模拟中，题库第一题位于 y=364，面经第一题 y=462，命令指南第一条 y=392。25 次跨页面切换无运行错误或浏览器崩溃。现有更新逻辑检测新版后直接 location.replace，已确认会中断阅读并重置当前页面；尚不能据此确定用户设备的进程退出原因，已询问具体表现。

实施：
- 顶栏显示当前页面名称，手机去掉重复主标题。
- 指南手机入口合并为一行，说明按需展开，常用命令改成连续紧凑列表。
- 题库手机收紧留白，次要卡片操作使用有无障碍标签的图标；面经去掉重复公司标题。
- 更新仅显示可关闭的提示；用户点击才刷新。相同版本的控制器切换不打断页面。
- 回归验证更新触发、编辑保护、手机触控、搜索、分类、复制、夜间、离线及持续切换。

验证结果：61 项 Node 测试通过；浏览器模拟旧文档 39 → 新 service worker 40，提示出现后仍停留在命令阅读页，点击更新才导航，本地存储保留，随后断网重载指南正常。忽略旧提示后再请求新版本的场景也有回归覆盖。360、390、768、1366px 下七个主视图无横向溢出，80 次页面切换无运行错误或模拟浏览器崩溃。手机指南首条 y=199，题库首题 y=288。真实手机浏览器进程退出尚未复现，仍需用户提供设备、浏览器及触发动作。
