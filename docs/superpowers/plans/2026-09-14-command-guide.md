# 命令指南实施计划

**目标：** 在学习资源加入独立阅读模块，使用用户提供的核心 40 条与完整手册，不写入题库或学习进度。

**设计：** 保留主导航“学习资源”，页面内分“命令指南 / 常用网站”。指南包含核心 40 条、分类手册、排查场景三个入口；支持全文检索、章节切换、复制命令。桌面左侧目录右侧阅读，手机使用章节选择器；沿用现有绿色主题和夜间模式。选择该方案以避免增加拥挤的主导航，也避免把长文堆在题目卡片中。

**架构：** 原始 Markdown 放在 assets/guides；Python 导入脚本生成独立 data/command-guide.js。command-guide.js 负责安全 Markdown 渲染和资源页交互，command-guide.css 负责响应式排版。仅替换 index.html 的资源页渲染入口。题库、笔记与抽查数据保持独立。
