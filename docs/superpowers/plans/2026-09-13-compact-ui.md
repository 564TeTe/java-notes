# 界面精简与紧凑布局

**目标：** 删除宣传式和重复文案，让题目、搜索、筛选和操作更快进入视野。

**设计：** 保持现有绿色与黑色主题、导航和数据逻辑。页头只保留标题和搜索；统计与主要操作压缩为工具栏；题目筛选按需展开；桌面列表工具与分页并排；手机保留可点击尺寸。抽查来源改为紧凑选项，简历和秋招的首屏突出实际进度与操作。

**实现：** 使用现有原生 HTML/CSS/JavaScript 模块与事件，不增加依赖。用户已授权自行判断并直接优化。

- [x] 精简题库、抽查、面经、简历、秋招的重复标题和无操作价值的说明。
- [x] 收紧全局导航、目录、列表工具、题目卡片和内容概览的布局。
- [x] 检查桌面、手机、黑色主题，以及搜索、筛选、分页、答题和主要入口。
- [x] 运行现有 Node 测试，更新缓存版本并审查最终变更。

**验证结果：** 51 项现有 Node 测试通过；浏览器检查搜索、筛选、分页设置与跳页、编辑器入口、抽查与掌握度、手机导航及深色主题，共 107 项检查通过。9 个页面在 320、390、768、1024、1440px 下均无横向溢出。秋招布局使用现有本地岗位快照验证。只读代码审查未发现需修复的回归。

**效果：** 1440×1000 下第一道题由约 487px 上移到约 261px。版本更新为 35，未改动用户数据与部署状态。
