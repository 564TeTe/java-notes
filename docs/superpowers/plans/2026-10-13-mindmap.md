# 思维导图 Implementation Plan

> **For agentic workers:** Use subagent-driven-development to implement independent units and review the integrated result.

**Goal:** 添加可离线使用、关联题库的知识导图和编辑器，不包含计划安排。

**Architecture:** 原生纯函数内核 + 独立 UI 模块，通过现有导航/渲染/备份接口接入。动态题库图读取当前学习记录；用户导图独立存储。

**Tech Stack:** JavaScript, SVG, CSS, Node test runner, Playwright browser validation.
