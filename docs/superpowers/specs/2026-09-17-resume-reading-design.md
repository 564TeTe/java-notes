# 简历问答背诵版

用户明确否定 v43 的填写与练习管理，要求直接背内容并增加真实面试追问。本次需求覆盖旧设计，以阅读为核心；本地完成后等待用户推送指令。

- 默认进入面试问答，答案直接可读；提供全部展开/遮住答案、关键词、经历与必会/深入筛选、分页。手机控制栏紧凑。
- 移除准备台、逐条填写、核实勾选、口述输入框、计时、自评、清单和回答复盘输入。保留介绍稿直接阅读、简历原句关联问答和资料入口。
- 旧个人记录不在页面展示，但通过原 snapshot 合约保留和恢复，避免升级时清空数据。
- 48 道问题扩展至约 140 道，覆盖整体介绍、知枢、北软、用友以及简历声明的技术基础。保留旧 ID。每道有实质参考回答、下一层追问与追问答案；明确区分个人已知实现和通用解决方法。
- 新增 `topic` 与 `priority`（must/deep）字段帮助按链路背诵；新增题目不得用换词凑数，不凭空补生产指标/数据库方案/职责。
- 技术知识依据官方文档核对，准备简洁引用清单放在资料页。新版 PDF 保持不变。
- 扩展内容单独文件；移除已不用的计时/编辑器实现与 CSS，保留精简旧记录适配层。新内容与样式纳入离线缓存，升级 v44。

验收：没有练习表单、计时和清单导航；首页可直接读答；分类/搜索/分页/遮答/关联定位可用；旧数据备份往返；140 道唯一问题有答案及连续追问；四主题手机桌面无溢出；离线可用。
