# 小林java：独立学习阅读模块

用户已确认独立模块方案，并明确要求更直观、以学习阅读为主，不必设计成题目。沿用现有网站主题，实现专题书架 → 章节连续阅读 → 知识小节的阅读路径。

## 内容与隔离

从 `E:/TEST/xiaolin-crawler/output/interview-bundle/pages/*/content.json` 转换全部 17 页：16 个问答专题包含 945 个知识小节，另一个专题为后端进阶资源索引。保留原文介绍、章节边界、完整答案、嵌套列表、代码语言、表格、原图 URL、原文锚点与作者。资源章节保留为链接与原有正文，不声称包含未采集文章。

以构建脚本生成独立 catalog 和每专题 JSON；不修改 question-bank，不加入原题库的数据集合、随机抽查、已背区、个人题库笔记或统计。资料仅渲染经过白名单清洗的 HTML，外链协议受限，图片失败提供原图链接。远程图片需要网络；文本随站点离线缓存。

## 交互与视觉

桌面导航和手机更多增加“小林java”。书架按六类组织专题，显示小节数与已读进度，提供继续阅读、收藏/笔记回看、标题和章节搜索。Java 基础作为建议起点。

阅读页采用纸张感的连续正文、清晰标题与宽松行距，保持现有主题色。左侧是专题选择和章节目录，正文上方为返回书架、字号和专注阅读。章节内全部小节展开，使用小节目录快速定位；每节支持读懂标记、收藏与自己的理解。上下章支持顺序阅读。手机目录为可收起面板，正文单列；表格和代码可横向滚动，整页不溢出。

## 状态与备份

用独立 `java-notes-xiaolin-v1` 本地存储保存小节状态、笔记、阅读位置和字号。保存失败明确提示；损坏状态不覆盖原存储。小节 ID 使用来源的稳定锚点；浏览位置只保存章节/小节，不自动宣称已学会。主站备份增加独立 `xiaolin` 字段；导入旧备份保留现有阅读记录，非法新字段在任何学习数据变化前拒绝。

## 验收

核对所有 945 个原答案逐字保留，生成 HTML 可安全显示图文、列表、代码与表格；单测覆盖索引、状态校验、搜索、备份兼容和题库隔离。浏览器验证桌面/手机、阅读跳转、笔记刷新恢复、专题加载失败重试、旧模块回归、离线阅读。同步更新应用版本与 service worker 资源列表。
