# 思维导图模块

用户选择综合知识学习，随后明确取消计划安排。本模块只用于知识总览、学习进度与自由整理，不包含日期、任务、日程或计划功能。

## 体验

- 桌面主导航与手机“更多”新增“思维导图”。沿用现有纸墨绿色主题，其他主题也可用。
- “知识总览”根据当前可用题库构建分类树，已背题仍显示，已删除题不显示。分类默认折叠，节点支持查看关联题目、答案预览和学习进度；状态随已有熟练度及已背记录变化。
- “我的导图”支持新建空白/知识梳理模板、复制题库总览或选中分支、多导图切换/重命名/复制/删除。
- 可编辑导图支持添加子节点和同级节点、改名、学习笔记、未学习/学习中/已掌握、题库关联、调整父节点与顺序、删除分支、撤销/重做。
- 画布支持拖动、缩放、适应画布、聚焦节点、展开/折叠、搜索并展开命中路径。提供大纲视图，方便小屏和键盘操作。
- 节点详情在桌面右侧、手机下方；按钮和字段均有可访问名称，编辑输入不触发画布快捷键。
- 自动本地保存；独立 JSON 导入导出和 SVG 图片导出；全站本地备份包括导图。旧备份缺少导图字段时保留当前导图。导入先校验再应用，错误不覆盖已有数据。

## 实现边界

原生 JavaScript/SVG/CSS，不增加网络依赖。`mindmap-core.js` 提供纯数据校验、树操作、知识总览与布局；`mindmap-module.js` 负责状态、视图与交互；`mindmap.css` 负责 scoped 样式。现有 shell / study 分支作最小接入，版本与离线资源统一更新。

导图快照 `{version:1, activeMapId, maps}`，每图 `{id,title,rootId,nodes}`，节点 `{id,parentId,title,note,status,questionId,collapsed}`。状态 `new/learning/mastered`，根节点 parentId 为 null。拒绝重复 ID、悬空父节点、循环、无效根与过大的文件；限制 30 张图、单图 1200 节点、深度 32、标题 160 字、笔记 10000 字。知识总览动态生成，不重复持久化。

## 验收

纯函数测试覆盖结构修改、非法导入、布局、题库映射与进度；集成测试覆盖导航、备份与旧备份兼容。浏览器实际检查创建/编辑/撤销/重载、搜索、关联跳转、图片导出、桌面和 390/320 小屏布局、主题切换及无控制台错误。运行现有 Node 全量回归与 diff 检查。
