# Java 学习思维导图改进

用户指出原总览只是题目导航，要求保留，同时加入真正基于 Java 知识的学习导图。不加入计划安排。

## 设计

思维导图页增加三个入口：默认“Java 学习”、原“题库导航”、原“我的导图”。Java 学习是一份人工组织的概念树，题目不充当知识节点。

覆盖语言基础、面向对象、泛型/集合、异常、I/O、并发、JVM，以及 JDBC、Web/Spring 和工程实践。每个知识节点提供简明要义、原理解释、示例、易错点、前置知识/关联概念和官方资料。节点标题直接表达知识概念，不使用面试问题句式。分支逐层展开，增加按专题聚焦的视图；跨概念关系可点击跳转。手机默认大纲。

学习内容适用于 Java 17 核心知识，涉及 records、虚拟线程等特性标明版本；后端扩展注明与 Java SE 的边界。详情中的相关题目通过明确关键词匹配辅助练习，不作为课程结构或掌握度的依据。

学习节点拥有独立的掌握状态与个人心得，保存在本地并包含在导图 JSON 和全站备份中。旧导图备份兼容，既有题库导航和个人导图不受影响。复制课程分支到“我的导图”时保留讲解为笔记。

## 实施

- 数据内容按语言/运行时/后端分组存放在 `data/java-learning-*.js`，无第三方运行时依赖。
- `java-learning-core.js` 负责内容索引、校验、概念树构造、学习进度快照和相关题目匹配。
- `mindmap-module.js` 接入专题、学习详情和独立进度；`mindmap-core.js` 只扩展可选快照字段以兼容旧数据。
- 保留已有编辑、缩放、搜索、导入导出功能，增加相关行为测试和浏览器验证。

## 验收

以一个从未刷题的人为标准：可以沿导图学习 Java 的概念与原理，看到例子和知识联系；题目全部移除后，课程仍完整可用。旧数据往返不丢失；学习笔记和掌握度刷新后保留；手机阅读可用；离线资料完整缓存。
