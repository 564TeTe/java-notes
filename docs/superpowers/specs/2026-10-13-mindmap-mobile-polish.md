# 手机导图布局优化

用户反馈专题导航和说明占屏过多，应突出知识导图，且删除底栏的通知数字。

## 已实现

- 手机页头使用紧凑文字和小图标，隐藏思维导图页的大幅主题横图。
- 专题改为单行可搜索选择框，说明文字收起，搜索/视图工具压为一行；新建、导入导出等操作放入更多菜单。
- 手机 Java 图采用当前概念与直属子概念的两列布局，保持可读字号；加号深入、上一级返回。桌面和SVG导出保留完整结构。
- 手机看图和讲解分屏切换；返回会保存待提交笔记并恢复键盘焦点。专注模式使用整个屏幕。
- 删除移动底栏更多及面板重点复习的数字角标；关闭更多面板立即隐藏，避免动画期间遮挡和截获点击。

## 验证

- 手机320、362、390、600及桌面1440像素实际浏览器验证，覆盖层级导航、跨专题搜索、阅读内知识关联、返回图/大纲、焦点、笔记保存、全屏、新建入口及深色主题，无页面错误与横向溢出。
- 审查修复深入分支与阅读目标不同步、隐藏画布按零尺寸定位以及大纲不可聚焦问题。
- 版本69刷新相关离线资源，旧学习状态与导图结构兼容。
