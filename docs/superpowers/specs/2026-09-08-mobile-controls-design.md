# 移动端控件与视觉优化

用户提供了四张截图，要求优化手机原生选择弹窗、题库与公司面经列表上方的空白、冗余解释文字，以及导航和应用图标。

延续现有绿色工作台，采用紧凑、清楚的工具界面。题数选择改为三个直接点选的按钮；其余移动端单选框提供页面内展开的选项，多选项列表可搜索，保持原有表单值和 change 事件。桌面继续使用标准表单控件。选择器支持键盘关闭、正确的焦点恢复，不将附件题目内容视为操作指令。

分页统一为紧凑的范围、前后翻页和当前页码，将每页数量、首页末页和跳转收进按需展开的设置。题库与公司面经共用；重置分类、切换页大小和搜索后仍正确限定范围。不删除分页功能。

删除 P0/P1/P2 来源解释及列表中重复的介绍文字，保留空状态、错误信息和真实来源记录。合并展开／收起答案为一个操作，缩短筛选条与列表标题的间距。

底部导航、更多入口和同步入口使用同一套 SVG 线条图标；应用图标使用深绿底的书页与勾选标记，更新 SVG、192/512 PNG、favicon、manifest 和状态栏配色。移动端编辑表单使用接近整屏的面板，有明确关闭入口和底部操作栏。

验证：现有 Node 测试；新增交互通过真实浏览器验证选项切换、搜索、页码、抽查、编辑器、键盘关闭、跨视图重复渲染、窄屏和离线缓存。保持已有题库与个人存储格式。

审查补充：按钮组声明选中状态，长列表支持上下方向键、Home/End 和 Enter，Escape 优先关闭选项再关闭表单。隐藏原生 select 后，焦点循环只包括可见控件。选择触发重新渲染后恢复至新触发器；每页数量改变后恢复至分页设置。重复增强、表单重开与桌面原生控件均验证数据一致。

旧缓存升级：受旧 Service Worker 控制的页面，在新版激活后自动切换完整资源；若正在编辑，则保留草稿并在关闭表单后提供刷新入口。通知位于编辑器下方，避免遮挡保存／取消按钮。

完成验证：27 项 Node 测试通过；360、390、768、1440px 无横向溢出；浏览器通过分类搜索、公司筛选、分页设置、限定抽查、表单保存与重置、键盘导航、重复增强和离线抽查。独立环境验证 v27 升级到 v29、首次导航生效、升级后离线加载以及草稿保护。
