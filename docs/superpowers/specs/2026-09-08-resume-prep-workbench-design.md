# 简历准备工作台设计

## 目标

把简历准备模块从资料目录改成面试前可直接使用的工作台。用户进入页面后，能立即知道整体进度、薄弱问题和下一步练习，并能按经历快速进入口述、深挖和模拟问答。

## 页面结构

保留现有功能页签，但调整首页信息层级：

1. 顶部工作台：展示总进度、已掌握题数、薄弱题数、清单进度和主要操作。
2. 今日建议：根据未练习/薄弱题和清单状态给出一条可执行建议。
3. 经历列表：四段经历改为紧凑行式布局，展示定位、题目进度和继续练习入口。
4. 准备路径：用简短步骤说明“自我介绍 → 经历深挖 → 模拟问答 → 冲刺清单”。
5. 原始资料：继续放在独立资料页，不抢占首页核心练习空间。

## 交互

- “开始练习”优先打开薄弱或未练习题；没有题目时进入模拟问答。
- “复习薄弱题”显示薄弱数量，无薄弱题时提示继续随机抽题。
- 经历行的“继续练习”按来源打开对应口述或问答筛选。
- 所有进度继续使用现有 localStorage 字段，保持数据兼容。

## 响应式要求

- 桌面端工作台采用左右分栏，右侧显示进度和建议。
- 移动端改为单列，经历列表每行只保留标题、进度和操作，避免大面积卡片空白。
- 保持现有键盘焦点、按钮语义和颜色系统。
