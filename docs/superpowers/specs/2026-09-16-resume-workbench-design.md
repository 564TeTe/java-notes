# 新版简历准备模块

用户要求根据 2026-09-16 提供的新版 PDF 完善简历准备；延续既有授权的紧凑、实用、少文案设计。此次在本地完成，不自动推送。

## 内容与交互

- 更新站内 PDF，逐条覆盖用友 4 条、北软 4 条、知枢 6 条经历。尤其补齐生产报工到计件工资、关联报工 ID 幂等、销售订单/开票/回款联动及数量校验。
- 保留旧问题 ID 和用户掌握/草稿；旧手册及案例明确为补充资料。参考回答区分 PDF 事实、待核实实现和可选改进，不把未验证的数据库约束、事务方案和性能数字写成用户成果。
- 首页展示新版简历日期、三个准备入口和实际记录数量，推荐下一条未核实经历或薄弱问答，不给自动能力评分。
- “逐条准备”按经历筛选，折叠条目展示简历原文、准备提示和对应追问。展开后填写本人职责、技术取舍、验证证据、待补问题四项，主动勾选已核实；编辑后撤销核实以免旧状态误导。
- “口述练习”一次展示一段稿件，支持选稿、个人草稿、默认收起参考稿、开始/暂停/重置计时、记录本次自评。仅计时，不录音、不调用 AI。切换页面或后台暂停，记录最近一次练习和卡顿点。
- 问答与清单保留，新增问题从简历条目直接定位。所有新增个人记录纳入现有完整备份和云同步对象。

## 实现边界

静态数据由 resume-data.js 和 resume-claims.js 管理。新增 resume-workbench.js/css 承载结构化记录与口述，resume-module.js 负责现有导航和快照集成。全站四主题与小屏适配，新增资产纳入离线缓存，版本升至 v43。
