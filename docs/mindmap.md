# 思维导图使用说明

桌面点击顶部“思维导图”；手机点击底部“更多 → 思维导图”。

## Java 学习

首次打开默认展示独立于题库的 Java 知识导图。按语言基础、面向对象、泛型与集合、异常与 I/O、函数式编程、并发、JVM、数据访问、Web / Spring、工程实践组织内容。

- 点击概念阅读原理、代码或场景示例、易错点与官方资料。内容以 Java 17 为核心，涉及更新特性时注明版本。
- 顶部专题和详情中的“只看这一支”缩小观察范围；“全部知识”回到全景。搜索覆盖全部 Java 概念，不局限当前专题。
- “先理解这些”“关联与对比”可直接跳转概念；“知识关联”显示已展开节点间的虚线关系，实线表示知识层级。
- 每个概念独立标记未学习、学习中、已掌握并写下“我的理解”。这些记录不修改题目熟练度；进度统计所有概念，不只统计叶子节点。
- “练习巩固”按概念术语匹配现有题目，作为理解后的练习入口。即使题库为空，知识内容仍然完整。
- 可复制当前知识分支及讲解、个人理解到“我的导图”，继续修改结构与内容。
- 复制时若讲解与个人理解合计超过单节点容量，会完整保留个人理解为附属节点，不截断笔记。

模块聚焦知识学习和观察，不包含计划、日程或任务安排。

## 题库导航

按现有题库分类展示知识树，保留已背题，排除回收站题目。选择节点查看分支进度或关联题目，在详情中展开答案、评价熟练度，也可跳转题库。

“已掌握”来自题目熟练度，“已背”来自已背区，两者分别统计。分类统计所有后代知识点，不受折叠影响。选择“复制这个分支到我的导图”可继续补充自己的理解。

## 自己整理知识

- “新建导图”从中心主题开始；“导图操作 → 新建知识梳理模板”提供概念、原理、场景和易错点四个分支。
- 在节点详情中修改名称、学习笔记和状态，输入后自动保存。中心主题也是导图名称。
- 添加子节点、同级节点；“调整结构”可更换所属节点、前后移动或删除整条分支。根节点不能移动或删除。
- 搜索题库并关联节点后，学习状态随题目熟练度同步；取消关联后可独立记录状态。
- 撤销/重做可恢复本次打开页面后的导图编辑，刷新会清空撤销历史。题目熟练度独立保存，不属于导图撤销范围。

## 观察与浏览

- 拖动画布平移；加减按钮、Ctrl/Command + 滚轮缩放；双指可缩放。
- “适应”显示完整展开范围，“定位”放大并居中当前节点。大图适应后字很小，可搜索具体节点定位。
- 点击节点选中，点击加减圆点或双击节点展开/折叠。搜索也会自动展开到匹配节点。
- 手机默认显示导图，Java 学习采用逐层浏览：当前概念连接直属分支，点加号继续深入，“上一级”返回父节点。节点保持可读字号，较长的分支可拖动查看。
- 手机专题入口收在一行选择框中，可搜索专题。点击概念进入讲解，“返回导图”继续观察；也可切换大纲或打开专注模式，让图占满屏幕。桌面保留完整导图和右侧讲解。
- Ctrl/Command + K 搜索；非输入状态下 Ctrl/Command + Z 撤销、Ctrl/Command + Shift + Z 重做；画布聚焦时方向键平移。专注模式通过按钮或 Esc 退出。

## 保存和迁移

数据保存在当前浏览器。导图操作中的 JSON 备份导出所有个人导图以及 Java 概念掌握度、个人理解。独立导入会追加导图副本并合并学习记录；同一概念有冲突时保留本机记录。全站“本地备份”也包含这些内容，导入全站备份会按原规则替换记录。旧备份缺少导图字段时保留当前导图，缺少 `learning` 字段时保留 Java 学习记录。

SVG 导出当前导图的全部节点，包括已折叠的内容，可用浏览器打开。Java 学习内容内置于应用并支持离线使用；题库导航从题库实时生成。若要编辑或固定一份结构，请先复制为个人导图。

导入上限为 8 MB，最多 30 张个人导图，每图最多 1200 节点、32 层。节点标题最多 160 字，笔记最多 10000 字。损坏数据会保留原始内容并提供导出入口，不会静默重置。浏览器拒绝保存时页面会明确提示。
