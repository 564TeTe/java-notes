## 筛选口径

这是结合当前 Java 后端主线与个人项目的复习优先级判断，不是面试频率统计，也不表示这些题不会考。保留 Java、集合、并发、JVM 常见原理、Spring、SQL、Redis、MQ、网络、Linux 排障、常见算法和业务场景题。难题不因难度高就移走。

简历包含 Spring Boot 控制面、Node 执行层的 Agent 编排项目，因此保留 Agent Loop、工具调用、MCP、SSE、审批与可靠执行等相关题，以及 RAG 的基本链路。暂移走的是更专门的知识库治理、检索参数和对话业务场景题。

岗位方向参考：[DXC 官方 Java 后端岗位](https://careers.dxc.com/job/23667885/back-end-developer-shanghai-cn/)明确列出 Spring Boot、数据库、Redis、API、集成与排障。这只能辅助判断岗位相关性，不能用来推断某题的面试频率。
